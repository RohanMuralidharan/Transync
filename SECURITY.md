# Security Policy

## Supported Versions

Security fixes are considered for the latest public version of Transync.

## Reporting a Vulnerability

Please do not open a public issue for a vulnerability. Send a private report to
the maintainers with:

- A short description of the issue.
- Steps to reproduce it.
- Affected files, commands, or inputs.
- Any known impact or workaround.

If no private security contact is configured for the repository yet, use GitHub
private vulnerability reporting before publishing details.

## Model Safety

Transync is a translation model package. It does not provide safety filtering,
content moderation, or factuality guarantees. Downstream applications should add
their own controls for sensitive deployments.
