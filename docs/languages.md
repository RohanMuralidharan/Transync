# Languages

Transync accepts compact language codes and maps them to FLORES-style tags.

| Code | Language | Model tag |
|---|---|---|
| `asm` | Assamese | `asm_Beng` |
| `ben` | Bengali | `ben_Beng` |
| `brx` | Bodo | `brx_Deva` |
| `doi` | Dogri | `doi_Deva` |
| `gom` | Konkani | `gom_Deva` |
| `guj` | Gujarati | `guj_Gujr` |
| `hin` | Hindi | `hin_Deva` |
| `kan` | Kannada | `kan_Knda` |
| `kas` | Kashmiri Arabic | `kas_Arab` |
| `kas_deva` | Kashmiri Devanagari | `kas_Deva` |
| `mai` | Maithili | `mai_Deva` |
| `mal` | Malayalam | `mal_Mlym` |
| `mar` | Marathi | `mar_Deva` |
| `mni` | Meitei Bengali | `mni_Beng` |
| `mni_mtei` | Meitei Meetei Mayek | `mni_Mtei` |
| `npi` | Nepali | `npi_Deva` |
| `ory` | Odia | `ory_Orya` |
| `pan` | Punjabi | `pan_Guru` |
| `san` | Sanskrit | `san_Deva` |
| `sat` | Santali | `sat_Olck` |
| `snd` | Sindhi Arabic | `snd_Arab` |
| `snd_deva` | Sindhi Devanagari | `snd_Deva` |
| `tam` | Tamil | `tam_Taml` |
| `tel` | Telugu | `tel_Telu` |
| `urd` | Urdu | `urd_Arab` |
| `eng` | English | `eng_Latn` |

Accepted aliases include `ban`, `ori`, `odi`, `pun`, `kas_arab`, `mni_beng`,
`snd_arab`, and `urd_arab`.
